# 工具识别战斗状态脚本

## 📖 功能说明

本脚本通过识别游戏屏幕上的特定图标来自动判断战斗状态，并在检测到战斗时自动启动自动战斗功能。同时集成了自动拾取（AutoPick）和自动剧情（AutoSkip）功能。

## ✨ 新增功能（v1.1）

### 攀爬/游泳/飞行状态检测豁免

**更新日期**: 2025-01-11

在原有功能的基础上，新增了对角色特殊移动状态的检测和豁免机制：

- ✅ **攀爬状态豁免**：当角色正在攀爬时，不会触发战斗检测
- ✅ **游泳状态豁免**：当角色正在游泳时，不会触发战斗检测
- ✅ **飞行状态豁免**：当角色正在飞行/滑翔时，不会触发战斗检测
- ✅ **交互状态豁免**：当出现交互提示时，不会触发战斗检测

### 为什么需要这个功能？

在之前的版本中，当角色处于攀爬、游泳或飞行状态时，由于工具栏也会被禁用（与战斗状态类似），可能会误触发自动战斗功能，导致：
- 攀爬过程中突然切换到战斗模式
- 游泳时意外启动战斗
- 飞行/滑翔时被打断
- 与NPC交互时被打断

现在通过识别屏幕右下角的状态图标，可以准确区分这些特殊移动状态，避免误触发。

## ⚙️ 配置选项

在 `settings.json` 中可以配置以下选项：

### 自动拾取设置
- **AutoPickEnabled**: 是否启用自动拾取功能（默认：true）
- **AutoPickTextList**: 自动拾取关键词，用逗号分隔（默认："拾取,采集,收集"）
- **ForceInteraction**: 强制交互模式，无视文本直接按F（默认：false）

### 自动剧情设置
- **AutoSkipEnabled**: 是否启用自动剧情跳过功能（默认：true）

### 战斗检测设置（新增）
- **IgnoreClimbState**: 攀爬时禁用战斗检测（默认：true）
- **IgnoreSwimState**: 游泳时禁用战斗检测（默认：true）
- **IgnoreFlyState**: 飞行时禁用战斗检测（默认：true）
- **IgnoreInteractionState**: 交互提示时禁用战斗检测（默认：true）

## 🔧 技术实现

### 状态检测机制

脚本使用模板匹配技术识别屏幕上的图标：

1. **工具栏禁用检测** (`Tooldisabled.png`)
   - 位置：屏幕右下角 (1800, 808)
   - 作用：判断是否可能进入战斗状态

2. **派蒙菜单检测** (`Paimon.png`)
   - 位置：屏幕左上角 (39, 31)
   - 作用：确认玩家在游戏主界面

3. **特殊移动状态检测**（新增）
   - **攀爬图标** (`Climb.png`): 位置 (1596, 1027)
   - **游泳图标** (`Swim.png`): 位置 (1811, 1027)
   - **飞行提示** (`Space.png`): 位置 (1683, 1027) 和 (1579, 1027)
   - **交互提示** (`Space.png`): 同上，根据上下文区分

### 检测流程

```
开始循环
  ↓
检测工具栏是否禁用？
  ├─ 否 → 继续循环
  └─ 是 ↓
派蒙菜单是否存在？
  ├─ 否 → 继续循环
  └─ 是 ↓
检测特殊移动状态
  ├─ 攀爬 → 跳过战斗检测
  ├─ 游泳 → 跳过战斗检测
  ├─ 飞行 → 跳过战斗检测
  ├─ 交互 → 跳过战斗检测
  └─ 正常 ↓
启动自动战斗
```

## 🎮 使用方法

1. 在BGI中加载此脚本
2. 根据需要调整 `settings.json` 中的配置
3. 启动脚本
4. 脚本会自动监控战斗状态并在合适时机启动自动战斗

## ⚠️ 注意事项

1. **分辨率要求**：脚本基于 1920x1080 分辨率设计，BGI会自动处理DPI缩放
2. **图标位置**：如果游戏UI有变化，可能需要重新截取图标并调整坐标
3. **性能影响**：状态检测会消耗一定的CPU资源，已经过优化以平衡性能和准确性
4. **误触发预防**：建议保持所有"状态豁免"选项为启用状态
