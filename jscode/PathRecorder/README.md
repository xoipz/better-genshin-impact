# PathRecorder - 路径录制工具

基于 BGI JavaScript 脚本的路径录制工具，带有实时 HTML HUD 界面。

## 功能特性

### ✅ 已实现功能

#### 核心录制
- **路径点录制** - 自动记录移动轨迹坐标
- **移动状态检测** - 自动识别行走/飞行/攀爬/游泳状态
- **智能路径优化** - RDP算法简化路径点，保留关键点

#### 传送检测
- **地图退出传送检测** - 从地图界面退出后自动检测传送
- **精确坐标获取** - 使用大地图获取传送点精确坐标
- **自动分段保存** - 传送时自动保存当前路径并开始新段

#### 状态管理
- **结束类型记录** - 记录录制结束原因 (fight/dialogue/pause/save/story)
- **继续录制支持** - 分析 process.json 恢复上次录制状态
- **最大循环保护** - 防止无限运行，达到上限自动保存

#### 移动模式处理
- **飞行段处理** - 自动添加 stop_flying 动作
- **攀爬段处理** - 根据时长决定 jump 或 climb 模式
- **游泳段处理** - 自动设置 swim 模式
- **回溯优化** - 长攀爬前自动将 dash 改为 walk

#### 交互功能
- **OCR对话处理** - 识别任务NPC名称并自动点击
- **战斗标记** - 添加战斗标记并可选执行自动战斗
- **暂停/恢复** - 完整的暂停恢复逻辑
- **导出功能** - 一键保存所有数据并结束录制

#### 自动功能集成
- **AutoSkip** - 自动跳过剧情
- **AutoPick** - 自动拾取
- **AutoEat** - 自动吃药
- **AutoFight** - 战斗标记时可选执行

#### HUD界面
- **实时状态显示** - 显示录制状态、坐标、步骤列表
- **步骤管理** - 支持删除、重命名步骤
- **快捷键提示** - 显示当前快捷键配置

## 快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| F6 | 录制(传送起点) | 开始录制，起点设为传送点 |
| F7 | 录制/暂停 | 开始或暂停录制 |
| F8 | 路径分段 | 保存当前路径，开始新段 |
| F9 | OCR对话 | 保存路径 + OCR识别NPC + 触发对话 |
| F10 | 战斗标记 | 保存路径 + 添加战斗标记 |
| F11 | 导出结束 | 保存所有数据并结束录制 |
| F12 | 显示/隐藏HUD | 切换HUD面板显示 |

## 配置说明

在 `settings.json` 中可配置：

- `questName` - 任务名称（用于文件命名）
- `questLocation` - 任务地点（用于文件夹组织）
- `author` - 作者名称
- `autoFight` - 是否启用自动战斗
- `forceTpFirst` - 首次录制是否自动设为传送点
- 各快捷键配置

## 输出文件

录制完成后，文件保存在：
```
process/{questLocation}/{questName}/
├── process.json          # 任务流程文件
├── {questName}-1.json    # 路径文件1
├── {questName}-2.json    # 路径文件2
└── ...
```

### process.json 格式

```
作者：User
地图追踪 Task-1.json
对话 派蒙
地图追踪 Task-2.json
战斗
地图追踪 Task-3.json
等待返回主界面
```

## 与 AutoStoryTranscribe 的区别

| 特性 | PathRecorder | AutoStoryTranscribe |
|------|-------------|---------------------|
| 交互方式 | 快捷键 + HTML HUD | 游戏菜单检测 |
| 状态显示 | 实时浮窗 | 仅日志 |
| 学习成本 | 低（快捷键直观）| 中（需记忆菜单配置）|
| 灵活性 | 高（随时可控）| 中（依赖界面状态）|
