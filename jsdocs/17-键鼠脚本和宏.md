# JavaScript脚本开发 - 键鼠脚本和宏录制功能

## 概述

BGI为JavaScript脚本提供了强大的键鼠宏录制和回放功能，允许脚本执行预录制的键盘鼠标操作序列。这个功能通过`keyMouseScript`对象暴露给JavaScript环境，基于BGI的宏录制系统实现。

**相关代码位置**:
- 键鼠脚本核心: `BetterGenshinImpact\Core\Script\Dependence\KeyMouseScript.cs:6-18`
- 宏播放器: `BetterGenshinImpact\Core\Recorder\KeyMouseMacroPlayer.cs`
- 对象注入: `BetterGenshinImpact\Core\Script\EngineExtend.cs:28`

## 核心方法

### run(json)
执行JSON格式的键鼠宏内容。

```javascript
// 执行键鼠宏JSON内容
const macroJson = `{
    "actions": [
        {"type": "keyDown", "key": "VK_W", "delay": 0},
        {"type": "sleep", "duration": 1000},
        {"type": "keyUp", "key": "VK_W", "delay": 0},
        {"type": "click", "x": 500, "y": 300, "delay": 100}
    ]
}`;

await keyMouseScript.run(macroJson);
```

**参数**:
- `json` (string): JSON格式的宏定义内容

**返回值**: Promise，宏执行完成后resolve

**代码位置**: `KeyMouseScript.cs:8-11`

### runFile(path)
执行指定路径的键鼠宏文件。

```javascript
// 执行宏文件
await keyMouseScript.runFile("macros/combat_combo.json");

// 执行移动宏
await keyMouseScript.runFile("macros/movement_sequence.json");

// 执行复杂操作序列
await keyMouseScript.runFile("macros/daily_routine.json");
```

**参数**:
- `path` (string): 宏文件的相对路径，相对于脚本项目根目录

**返回值**: Promise，宏执行完成后resolve

**安全限制**:
- 只能访问脚本项目目录内的文件
- 文件必须是有效的JSON格式
- 受到LimitedFile的安全策略保护

**代码位置**: `KeyMouseScript.cs:13-17`

## 宏文件格式

### 基础宏结构

```json
{
    "name": "示例宏",
    "version": "1.0",
    "actions": [
        {
            "type": "keyDown",
            "key": "VK_W",
            "delay": 0
        },
        {
            "type": "sleep", 
            "duration": 1000
        },
        {
            "type": "keyUp",
            "key": "VK_W",
            "delay": 0
        }
    ]
}
```

### 支持的操作类型

#### 1. 键盘操作
```json
// 按下按键
{
    "type": "keyDown",
    "key": "VK_W",
    "delay": 0
}

// 释放按键
{
    "type": "keyUp", 
    "key": "VK_W",
    "delay": 50
}

// 按键点击
{
    "type": "keyPress",
    "key": "VK_SPACE",
    "delay": 100
}
```

#### 2. 鼠标操作
```json
// 鼠标点击
{
    "type": "click",
    "x": 500,
    "y": 300,
    "delay": 100
}

// 鼠标移动
{
    "type": "mouseMove",
    "x": 800,
    "y": 600,
    "delay": 50
}

// 鼠标拖拽
{
    "type": "mouseDrag",
    "startX": 100,
    "startY": 100,
    "endX": 500,
    "endY": 300,
    "duration": 1000
}
```

#### 3. 延时操作
```json
// 等待指定时间
{
    "type": "sleep",
    "duration": 2000
}
```

## 最佳实践

### 1. 宏文件组织
```javascript
// ✅ 推荐：按功能分类组织宏文件
const macroCategories = {
    combat: [
        "macros/combat/basic_combo.json",
        "macros/combat/ultimate_combo.json"
    ],
    movement: [
        "macros/movement/forward_walk.json", 
        "macros/movement/exploration.json"
    ],
    interaction: [
        "macros/interaction/menu_navigation.json",
        "macros/interaction/dialog_skip.json"
    ]
};

// 批量执行宏
async function executeMacroCategory(category) {
    for (const macroPath of macroCategories[category]) {
        await keyMouseScript.runFile(macroPath);
        await sleep(500); // 宏之间的间隔
    }
}
```

### 2. 错误处理和重试
```javascript
async function safeExecuteMacro(macroPath, maxRetries = 3) {
    for (let attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            log.debug(`执行宏 ${macroPath} 第 ${attempt} 次尝试`);
            await keyMouseScript.runFile(macroPath);
            log.info(`宏 ${macroPath} 执行成功`);
            return;
        } catch (error) {
            log.warn(`宏执行第 ${attempt} 次尝试失败: ${error.message}`);
            if (attempt === maxRetries) {
                throw new Error(`宏 ${macroPath} 执行失败，已重试 ${maxRetries} 次`);
            }
            await sleep(1000 * attempt); // 递增延时重试
        }
    }
}
```

### 3. 宏执行监控
```javascript
class MacroMonitor {
    constructor() {
        this.executionStats = {
            totalExecuted: 0,
            successful: 0,
            failed: 0,
            averageTime: 0
        };
    }
    
    async executeWithMonitoring(macroPath) {
        const startTime = Date.now();
        this.executionStats.totalExecuted++;
        
        try {
            await keyMouseScript.runFile(macroPath);
            this.executionStats.successful++;
            
            const duration = Date.now() - startTime;
            this.updateAverageTime(duration);
            
            log.info(`宏执行成功 - 用时: ${duration}ms`);
        } catch (error) {
            this.executionStats.failed++;
            log.error(`宏执行失败: ${error.message}`);
            throw error;
        }
    }
    
    updateAverageTime(newDuration) {
        const total = this.executionStats.successful;
        this.executionStats.averageTime = 
            (this.executionStats.averageTime * (total - 1) + newDuration) / total;
    }
    
    getStats() {
        return {
            ...this.executionStats,
            successRate: (this.executionStats.successful / this.executionStats.totalExecuted * 100).toFixed(2) + '%'
        };
    }
}
```

## 注意事项

### ⚠️ 重要提醒

1. **取消支持**: 宏执行过程支持取消令牌，会响应 `CancellationContext.Instance.Cts.Token`
2. **文件安全**: 宏文件受到 `LimitedFile` 安全策略保护，只能访问项目目录内文件
3. **JSON格式**: 宏文件必须是有效的JSON格式，格式错误会导致执行失败
4. **延时设置**: 合理设置操作间的延时，避免操作过快导致游戏无响应

### ❌ 常见错误

```javascript
// ❌ 错误：文件路径不正确
await keyMouseScript.runFile("../../../system/dangerous.json"); // 会被安全策略阻止

// ❌ 错误：JSON格式错误
const invalidMacro = `{"type": "click" "x": 100}`; // 缺少逗号
await keyMouseScript.run(invalidMacro); // 会抛出JSON解析错误
```

### ✅ 正确用法

```javascript
// ✅ 正确：相对路径访问项目内文件
await keyMouseScript.runFile("macros/valid_macro.json");

// ✅ 正确：有效的JSON格式
const validMacro = {
    "actions": [
        {"type": "click", "x": 100, "y": 200, "delay": 100}
    ]
};
await keyMouseScript.run(JSON.stringify(validMacro));
```
