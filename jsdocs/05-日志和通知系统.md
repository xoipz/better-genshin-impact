# JavaScript脚本开发 - 日志和通知系统

## 概述

BGI为JavaScript脚本提供了完整的日志记录和通知推送系统，支持多种日志级别和多样化的通知方式。开发者可以使用这些功能来调试脚本、记录运行状态和接收重要消息。

**相关代码位置**:
- **日志系统**: `BetterGenshinImpact\Core\Script\Dependence\Log.cs` (全文28行)
- **通知系统**: `BetterGenshinImpact\Core\Script\Dependence\Notification.cs` (全文159行)
- **通知服务**: `BetterGenshinImpact\Service\Notification\NotificationService.cs`
- **引擎注册位置**: `EngineExtend.cs:35` (log对象), `EngineExtend.cs:38` (notification对象)

## 日志系统 (Log)

### 日志级别

BGI提供四个标准日志级别，按严重程度从低到高：

```javascript
// Debug - 调试信息
log.debug('这是调试信息');

// Info - 一般信息  
log.info('脚本启动成功');

// Warn - 警告信息
log.warn('检测到异常情况，但可以继续运行');

// Error - 错误信息
log.error('发生严重错误');
```

- Debug方法: `Log.cs:9-12`
- Info方法: `Log.cs:14-17`

## 通知系统 (Notification)

### 基础通知功能

BGI通知系统提供了以下方法，仅需启用权限即可使用，无内容长度限制和频率限制：

```javascript
// 发送通用通知
notification.send('所有日常任务已成功完成！');

// 发送错误通知
notification.error('执行过程中遇到异常，请检查日志');

// 发送带图片的通知（通过文件路径）
notification.sendWithImage('任务完成截图', 'C:\\path\\to\\image.png');

// 发送带图片的通知（通过游戏截图 ImageRegion）
const region = captureGameRegion();
notification.sendWithImage('当前游戏画面', region);

// 发送带图片的通知（通过 Mat 对象）
const mat = region.SrcMat;
notification.sendWithImage('处理后的图像', mat);
```

**代码位置**:
- Send方法: `Notification.cs:40-49`
- SendWithImage方法（文件路径）: `Notification.cs:57-80`
- SendWithImage方法（ImageRegion）: `Notification.cs:87-103`
- SendWithImage方法（Mat）: `Notification.cs:110-129`
- Error方法: `Notification.cs:148-158`

**⚠️ 重要变更说明**：
- 实际可用的方法是 `notification.send()`、`notification.sendWithImage()` 和 `notification.error()`
- `notification.success()` 和 `notification.info()` 方法在源码中不存在
- 所有方法的消息参数均为 `message` 字符串，不需要 `title` 参数
- 已取消内容长度限制（原500字符限制）和频率限制（原每分钟5条限制）

### 通知权限机制

通知系统采用两级权限验证机制：

```javascript
// 第一级：全局开关（在BGI设置中配置）
// 需要在"调度器通用设置"中启用"JS通知权限"

// 第二级：项目级别权限（在manifest.json中配置）
// 脚本项目可以选择是否允许发送通知
```

**权限检查逻辑**:
- 全局开关关闭 → 所有通知被拦截，记录警告日志
- 项目级别禁用 → 该项目的通知被拦截，记录警告日志
- 两级都启用 → 通知正常发送

**代码位置**: `Notification.cs:22-34` (CheckNotificationPermission方法)

### SendWithImage 方法详解

`sendWithImage` 支持三种图片来源，系统会根据第二个参数的类型自动匹配：

#### 1. 通过文件路径发送

```javascript
// 支持 png/jpg/bmp/webp 等常见图片格式
notification.sendWithImage('任务完成', 'screenshots/result.png');

// 使用绝对路径
notification.sendWithImage('异常截图', 'C:\\Users\\screenshots\\error.png');
```

**注意**: 如果文件不存在，会记录警告日志但不会抛出异常。

#### 2. 通过 captureGameRegion() 截图发送

```javascript
// 截取当前游戏画面并发送通知
const region = captureGameRegion();
notification.sendWithImage('当前游戏状态', region);

// 可以先裁剪再发送
const cropped = region.DeriveCrop(100, 200, 300, 50);
notification.sendWithImage('识别区域截图', cropped);
```

**说明**: 使用 `ImageRegion` 的 `CacheImage` 属性获取 `Image<Rgb24>` 图像数据。

#### 3. 通过 Mat 对象发送

```javascript
// 读取本地图片为 Mat 后发送
const mat = file.readImageMatSync('assets/template.png');
notification.sendWithImage('模板图片', mat);

// 使用 ImageRegion 的 SrcMat
const region = captureGameRegion();
notification.sendWithImage('原始截图', region.SrcMat);
```

**说明**: Mat 对象会自动进行 BGR→RGB 颜色空间转换后发送。

## 综合使用示例

### 完整的日志和通知集成

```javascript
async function automatedTaskWithNotifications() {
    const startTime = Date.now();
    let successCount = 0;
    let totalTasks = 0;
    
    try {
        log.info('=== 自动化任务开始 ===');
        notification.send('开始执行自动化任务序列');
        
        // 读取任务配置
        const config = loadScriptConfig();
        if (!config) {
            throw new Error('无法加载配置文件');
        }
        
        const tasks = config.tasks || ['默认任务'];
        totalTasks = tasks.length;
        
        log.info(`准备执行 ${totalTasks} 个任务`);
        
        // 执行任务列表
        for (let i = 0; i < tasks.length; i++) {
            const task = tasks[i];
            log.info(`开始执行任务 ${i + 1}/${totalTasks}: ${task.name}`);
            
            try {
                await executeTaskWithRetry(task);
                successCount++;
                log.info(`✓ 任务 "${task.name}" 完成`);
                
                // 进度通知（仅在特定间隔发送）
                if ((i + 1) % 3 === 0 || i === tasks.length - 1) {
                    notification.send(`任务进度: 已完成 ${i + 1}/${totalTasks} 个任务`);
                }
                
            } catch (error) {
                log.error(`✗ 任务 "${task.name}" 失败: ${error.message}`);
                
                // 错误通知
                notification.error(`任务 "${task.name}" 执行失败: ${error.message}`);
            }
            
            // 任务间延时
            if (i < tasks.length - 1) {
                await sleep(2000);
            }
        }
        
    } catch (error) {
        log.error('自动化任务异常终止:', error.message);
        notification.error(`自动化过程异常终止: ${error.message}`);
    } finally {
        // 最终统计
        const duration = Math.floor((Date.now() - startTime) / 1000);
        const successRate = totalTasks > 0 ? (successCount / totalTasks * 100).toFixed(1) : 0;
        
        log.info('=== 任务执行完成 ===');
        log.info(`总任务数: ${totalTasks}`);
        log.info(`成功完成: ${successCount}`);
        log.info(`成功率: ${successRate}%`);
        log.info(`总用时: ${Math.floor(duration / 60)}分${duration % 60}秒`);
        
        // 完成通知
        const isSuccess = successCount === totalTasks;
        const message = `任务${isSuccess ? '全部' : '部分'}完成 - ` +
            `成功: ${successCount}/${totalTasks} (${successRate}%) ` +
            `用时: ${Math.floor(duration / 60)}分${duration % 60}秒`;
        
        if (isSuccess) {
            notification.send(message);
        } else {
            notification.error(message);
        }
    }
}

async function executeTaskWithRetry(task, maxRetries = 3) {
    for (let attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            log.debug(`任务 "${task.name}" 第 ${attempt} 次尝试`);
            
            // 这里是实际的任务执行逻辑
            await performTask(task);
            
            return; // 成功则返回
            
        } catch (error) {
            log.warn(`任务 "${task.name}" 第 ${attempt} 次尝试失败: ${error.message}`);
            
            if (attempt === maxRetries) {
                throw error; // 最后一次尝试失败则抛出错误
            }
            
            // 重试前等待
            await sleep(1000 * attempt);
        }
    }
}
```

### 调试和监控

```javascript
class TaskMonitor {
    constructor() {
        this.stats = {
            startTime: Date.now(),
            operationCounts: {},
            errors: []
        };
    }
    
    logOperation(operationType) {
        this.stats.operationCounts[operationType] = 
            (this.stats.operationCounts[operationType] || 0) + 1;
        
        log.debug(`操作统计 - ${operationType}: ${this.stats.operationCounts[operationType]}`);
    }
    
    logError(error, context = '') {
        const errorInfo = {
            timestamp: new Date().toISOString(),
            message: error.message,
            context: context
        };
        
        this.stats.errors.push(errorInfo);
        log.error(`[${context}] ${error.message}`);
    }
    
    generateReport() {
        const duration = Date.now() - this.stats.startTime;
        const report = {
            运行时长: `${Math.floor(duration / 60000)}分${Math.floor((duration % 60000) / 1000)}秒`,
            操作统计: this.stats.operationCounts,
            错误数量: this.stats.errors.length,
            错误详情: this.stats.errors
        };
        
        log.info('=== 监控报告 ===');
        log.info(JSON.stringify(report, null, 2));
        
        return report;
    }
}

// 使用示例
const monitor = new TaskMonitor();

async function monitoredTask() {
    try {
        monitor.logOperation('点击操作');
        click(100, 200);
        
        monitor.logOperation('传送操作'); 
        await genshin.tp(1000, 2000);
        
    } catch (error) {
        monitor.logError(error, '执行主要任务时');
    } finally {
        const report = monitor.generateReport();
        
        notification.send(
            `任务监控报告 - 运行时长: ${report.运行时长}, ` +
            `总操作数: ${Object.values(report.操作统计).reduce((a, b) => a + b, 0)}, ` +
            `错误数量: ${report.错误数量}`
        );
    }
}
```

## 最佳实践

### 1. 日志级别选择
- **Debug**: 详细的调试信息，生产环境可关闭
- **Info**: 重要的状态变化和里程碑事件
- **Warn**: 需要注意但不影响继续执行的问题
- **Error**: 严重错误，可能导致任务失败

### 2. 通知频率控制
```javascript
class NotificationThrottler {
    constructor(intervalMs = 5000) {
        this.lastNotificationTime = {};
        this.interval = intervalMs;
    }
    
    canSendNotification(key) {
        const now = Date.now();
        const lastTime = this.lastNotificationTime[key] || 0;
        
        if (now - lastTime >= this.interval) {
            this.lastNotificationTime[key] = now;
            return true;
        }
        return false;
    }
}

const notifyThrottler = new NotificationThrottler();

function throttledNotify(key, message) {
    if (notifyThrottler.canSendNotification(key)) {
        notification.send(message);
    }
}
```

### 3. 错误分类和处理
```javascript
function handleScriptError(error, context) {
    if (error.name === 'NetworkError') {
        log.warn(`网络错误 [${context}]: ${error.message}`);
        notification.send('检测到网络异常，请检查网络连接');
    } else if (error.name === 'TimeoutError') {
        log.warn(`超时错误 [${context}]: ${error.message}`);
        // 超时通常不需要通知
    } else {
        log.error(`未知错误 [${context}]: ${error.message}`);
        notification.error(`发生未知错误: ${error.message}`);
    }
}
```
