**⚠️ 重要变更说明**：

### 通知安全机制

通知系统内置了完整的安全验证和频率限制机制，确保通知功能不被滥用。

**代码位置**: `Notification.cs:25-62` (权限检查、内容验证、频率限制)

#### 1. 权限检查（两级验证）

通知系统采用两级权限验证机制：

```javascript
// 第一级：全局开关（在BGI设置中配置）
// 需要在"调度器通用设置"中启用"JS通知权限"

// 第二级：项目级别权限（在manifest.json中配置）
// 脚本项目可以选择是否允许发送通知
```

**权限检查逻辑**:
- 全局开关关闭 → 所有通知被拦截，记录警告日志
- 项目级别禁用 → 该项目的通知被拦截，记录警告日志
- 两级都启用 → 通知可以发送（仍需通过内容验证和频率限制）

**代码位置**: `Notification.cs:25-37` (CheckNotificationPermission方法)

#### 2. 内容验证（安全过滤）

通知内容必须通过严格的安全验证：

```javascript
// ✅ 允许的内容
notification.send('任务完成，共采集了50个材料');
notification.send('当前树脂: 160/160');

// ❌ 被拦截的内容（包含危险模式）
notification.send('访问 http://example.com 查看详情');  // 包含http://
notification.send('点击 https://evil.com');             // 包含https://
notification.send('<script>alert("xss")</script>');     // 包含<script>

// ❌ 被拦截的内容（超过长度限制）
const longMessage = 'x'.repeat(501);
notification.send(longMessage);  // 超过500字符
```

**内容限制规则**:
- **最大长度**: 500字符（超过则被拦截）
- **禁止模式**:
  - `<script>` - 防止XSS攻击
  - `http://` - 防止恶意链接
  - `https://` - 防止恶意链接
- **检查方式**: 不区分大小写的模式匹配

**代码位置**: `Notification.cs:39-45` (ValidateContent方法)

#### 3. 频率限制（防止滥用）

通知系统采用滑动窗口算法限制发送频率：

```javascript
// 频率限制参数
const TIME_WINDOW = 60000;      // 时间窗口：1分钟（60秒）
const MAX_NOTIFICATIONS = 5;    // 最大通知数：5条

// 示例：频率限制演示
async function demonstrateRateLimit() {
    // 前5条通知会成功发送
    for (let i = 1; i <= 5; i++) {
        notification.send(`通知 ${i}/5`);  // ✅ 成功
        await sleep(100);
    }

    // 第6条及以后的通知会被拦截（1分钟内）
    notification.send('第6条通知');  // ❌ 被拦截，记录警告日志
    notification.send('第7条通知');  // ❌ 被拦截，记录警告日志

    // 等待1分钟后，频率限制重置
    await sleep(60000);
    notification.send('1分钟后的通知');  // ✅ 成功
}
```

**频率限制机制**:
- **时间窗口**: 1分钟（60秒）
- **最大通知数**: 5条
- **算法**: 滑动窗口，自动清理过期记录
- **超限行为**: 静默拦截，记录警告日志，不抛出异常

**代码位置**: `Notification.cs:48-62` (CheckRateLimit方法)

## 综合使用示例

### 完整的日志和通知集成

```javascript
async function automatedTaskWithNotifications() {
    const startTime = Date.now();
    let successCount = 0;
    let totalTasks = 0;
    
    try {
        log.info('=== 自动化任务开始 ===');
        notification.send('开始执行自动化任务序列');
        
        // 读取任务配置
        const config = loadScriptConfig();
        if (!config) {
            throw new Error('无法加载配置文件');
        }
        
        const tasks = config.tasks || ['默认任务'];
        totalTasks = tasks.length;
        
        log.info(`准备执行 ${totalTasks} 个任务`);
        
        // 执行任务列表
        for (let i = 0; i < tasks.length; i++) {
            const task = tasks[i];
            log.info(`开始执行任务 ${i + 1}/${totalTasks}: ${task.name}`);
            
            try {
                await executeTaskWithRetry(task);
                successCount++;
                log.info(`✓ 任务 "${task.name}" 完成`);
                
                // 进度通知（仅在特定间隔发送）
                if ((i + 1) % 3 === 0 || i === tasks.length - 1) {
                    notification.send(`任务进度: 已完成 ${i + 1}/${totalTasks} 个任务`);
                }
                
            } catch (error) {
                log.error(`✗ 任务 "${task.name}" 失败: ${error.message}`);
                
                // 错误通知
                notification.error(`任务 "${task.name}" 执行失败: ${error.message}`);
            }
            
            // 任务间延时
            if (i < tasks.length - 1) {
                await sleep(2000);
            }
        }
        
    } catch (error) {
        log.error('自动化任务异常终止:', error.message);
        notification.error(`自动化过程异常终止: ${error.message}`);
    } finally {
        // 最终统计
        const duration = Math.floor((Date.now() - startTime) / 1000);
        const successRate = totalTasks > 0 ? (successCount / totalTasks * 100).toFixed(1) : 0;
        
        log.info('=== 任务执行完成 ===');
        log.info(`总任务数: ${totalTasks}`);
        log.info(`成功完成: ${successCount}`);
        log.info(`成功率: ${successRate}%`);
        log.info(`总用时: ${Math.floor(duration / 60)}分${duration % 60}秒`);
        
        // 完成通知
        const isSuccess = successCount === totalTasks;
        const message = `任务${isSuccess ? '全部' : '部分'}完成 - ` +
            `成功: ${successCount}/${totalTasks} (${successRate}%) ` +
            `用时: ${Math.floor(duration / 60)}分${duration % 60}秒`;
        
        if (isSuccess) {
            notification.send(message);
        } else {
            notification.error(message);
        }
    }
}

async function executeTaskWithRetry(task, maxRetries = 3) {
    for (let attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            log.debug(`任务 "${task.name}" 第 ${attempt} 次尝试`);
            
            // 这里是实际的任务执行逻辑
            await performTask(task);
            
            return; // 成功则返回
            
        } catch (error) {
            log.warn(`任务 "${task.name}" 第 ${attempt} 次尝试失败: ${error.message}`);
            
            if (attempt === maxRetries) {
                throw error; // 最后一次尝试失败则抛出错误
            }
            
            // 重试前等待
            await sleep(1000 * attempt);
        }
    }
}
```

### 调试和监控

```javascript
class TaskMonitor {
    constructor() {
        this.stats = {
            startTime: Date.now(),
            operationCounts: {},
            errors: []
        };
    }
    
    logOperation(operationType) {
        this.stats.operationCounts[operationType] = 
            (this.stats.operationCounts[operationType] || 0) + 1;
        
        log.debug(`操作统计 - ${operationType}: ${this.stats.operationCounts[operationType]}`);
    }
    
    logError(error, context = '') {
        const errorInfo = {
            timestamp: new Date().toISOString(),
            message: error.message,
            context: context
        };
        
        this.stats.errors.push(errorInfo);
        log.error(`[${context}] ${error.message}`);
    }
    
    generateReport() {
        const duration = Date.now() - this.stats.startTime;
        const report = {
            运行时长: `${Math.floor(duration / 60000)}分${Math.floor((duration % 60000) / 1000)}秒`,
            操作统计: this.stats.operationCounts,
            错误数量: this.stats.errors.length,
            错误详情: this.stats.errors
        };
        
        log.info('=== 监控报告 ===');
        log.info(JSON.stringify(report, null, 2));
        
        return report;
    }
}

// 使用示例

            `总操作数: ${Object.values(report.操作统计).reduce((a, b) => a + b, 0)}, ` +
            `错误数量: ${report.错误数量}`
        );
    }
}
```

## 最佳实践

### 1. 日志级别选择
- **Debug**: 详细的调试信息，生产环境可关闭
- **Info**: 重要的状态变化和里程碑事件
- **Warn**: 需要注意但不影响继续执行的问题
- **Error**: 严重错误，可能导致任务失败

### 2. 通知频率控制
```javascript
class NotificationThrottler {
    constructor(intervalMs = 5000) {
        this.lastNotificationTime = {};
        this.interval = intervalMs;
    }
    
    canSendNotification(key) {
        const now = Date.now();
        const lastTime = this.lastNotificationTime[key] || 0;
        
        if (now - lastTime >= this.interval) {
            this.lastNotificationTime[key] = now;
            return true;
        }
        return false;
    }
}

const notifyThrottler = new NotificationThrottler();

function throttledNotify(key, message) {
    if (notifyThrottler.canSendNotification(key)) {
        notification.send(message);
    }
}
```

### 3. 错误分类和处理
```javascript
function handleScriptError(error, context) {
    if (error.name === 'NetworkError') {
        log.warn(`网络错误 [${context}]: ${error.message}`);
        notification.send('检测到网络异常，请检查网络连接');
    } else if (error.name === 'TimeoutError') {
        log.warn(`超时错误 [${context}]: ${error.message}`);
        // 超时通常不需要通知
    } else {
        log.error(`未知错误 [${context}]: ${error.message}`);
        notification.error(`发生未知错误: ${error.message}`);
    }
}
```
