# BGI JavaScript脚本文档编写规则与收集标准

## 概述

本文档制定了BGI（BetterGenshinImpact）JavaScript脚本开发相关文档的编写规则、格式标准和内容收集规范。适用于所有相关技术文档的创建、更新和维护工作。

---

## 1. 文档命名规范

### 1.1 核心文档命名规则
- **索引文档**: `00-` 开头，如 `00-完整代码位置索引.md`
- **功能文档**: `01-` 到 `99-` 开头，如 `01-全局方法API.md`
- **指南文档**: 完整标题，如 `BGI_JavaScript脚本项目开发完整指南.md`

### 1.2 命名原则
- 使用中文描述性名称
- 数字前缀确保文档排序
- 文件名避免特殊字符和空格
- 扩展名统一使用 `.md`

---

### 2.1 标准文档结构

## 最佳实践

## 注意事项

```

### 2.2 必需元素
1. **标题**: 使用 `#` 级别标题，清晰表达文档主题
2. **概述章节**: 必须包含功能概述和代码位置
3. **代码示例**: 每个功能都要有实际可用的代码示例
4. **相关代码位置**: 格式为 `文件路径:行号范围`

## 3. 内容编写规范

### 3.1 BGI功能记录原则

**重要声明**: 本文档系列记录的是BGI为JavaScript提供的功能，而非JavaScript脚本项目本身的功能。

#### 记录范围
✅ **应该记录的内容**:
- BGI暴露给JS的API方法
- BGI提供的全局对象和函数
- BGI的系统功能和接口
- BGI的配置选项和参数
- BGI的识别和自动化能力

❌ **不应记录的内容**:
- 第三方JavaScript库的使用
- 纯JavaScript语法和特性
- 具体脚本项目的业务逻辑
- 用户自定义的功能模块

### 3.2 代码位置标注规范

**格式**: `相关代码位置: 文件路径:行号范围`

**示例**:
```markdown
**相关代码位置**: `BetterGenshinImpact\Core\Script\Dependence\GlobalMethod.cs:20-295`

**代码位置**: `GlobalMethod.cs:22-25`
```

**要求**:
- 每个功能都必须标注源码位置
- 使用相对于项目根目录的路径
- 行号范围要准确，便于开发者定位
- 重要功能要标注多个相关代码位置

### 3.3 功能状态标注

对于功能的可用性状态，使用以下标注：

```markdown
## 传送功能【人工标注：未知功能】
## 某某API【已验证】
## 某某方法【实验性功能】
## 某某接口【已废弃】
```

**状态类型**:
- `【已验证】`: 经过测试确认可用
- `【未知功能】`: 存在于代码中但使用效果未知
- `【实验性功能】`: 功能不稳定，可能变更
- `【已废弃】`: 不再建议使用的功能

## 4. 代码示例编写规范

### 4.1 示例代码要求
- 使用JavaScript语法高亮：``javascript``
- 提供完整可运行的示例
- 包含参数说明和返回值描述
- 添加必要的注释

### 4.2 示例代码格式
```markdown
### 方法名称
功能描述文字

```javascript
// 基础用法
await methodName(param1, param2);

// 高级用法示例
const result = await methodName(param1, param2, optionalParam);
if (result.success) {
    log.info('操作成功');
}
```

**参数**:
- `param1` (type): 参数描述
- `param2` (type): 参数描述

**返回值**: 返回值类型和描述

**代码位置**: `文件.cs:行号`
```

### 4.3 错误示例标注

对于常见错误，使用以下格式：

```markdown
```javascript
// ❌ 错误：不支持的用法
someMethod('invalid_param');

// ✅ 正确：推荐的用法  
someMethod('valid_param');
```
```

## 9. 收集和更新流程

### 9.1 新功能发现流程
1. **发现阶段**: 在代码中发现新的BGI功能
2. **验证阶段**: 编写测试代码验证功能
3. **文档阶段**: 按照规范编写功能文档
4. **索引更新**: 更新00系列索引文档

### 9.2 文档维护流程
1. **定期检查**: 定期检查BGI源码变更
2. **功能验证**: 重新验证已记录功能的有效性
3. **文档更新**: 更新过时或不准确的描述
4. **版本标注**: 更新文档版本和变更记录

### 9.3 质量检查清单
- [ ] 代码位置标注完整且准确
- [ ] 示例代码可实际运行
- [ ] 参数和返回值描述准确
- [ ] 包含错误处理示例
- [ ] 交叉引用链接有效
- [ ] 遵循统一格式规范
