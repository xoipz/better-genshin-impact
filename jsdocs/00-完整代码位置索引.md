## 重要说明：C#与JavaScript方法名约定

### 方法名大小写自动转换

BGI使用Microsoft ClearScript V8引擎，在JavaScript中调用C#方法时，会自动进行命名约定转换：

**转换规则**: C#的PascalCase（首字母大写）→ JavaScript的camelCase（首字母小写）

#### 转换示例

| C#源码中的方法名 | JavaScript中的调用方式 | 说明 |
|----------------|---------------------|------|
| `SwitchParty(string)` | `genshin.switchParty(string)` | S → s |
| `ClearPartyCache()` | `genshin.clearPartyCache()` | C → c |
| `GetPositionFromMap()` | `genshin.getPositionFromMap()` | G → g |
| `ReadTextSync(string)` | `file.readTextSync(string)` | R → r |
| `WriteImageSync(string, Mat)` | `file.writeImageSync(string, mat)` | W → w |
| `OnKeyDown(callback)` | `hook.onKeyDown(callback)` | O → o |

#### 实际代码对比

**C#源码** (`Genshin.cs:266`):
```csharp
public async Task<bool> SwitchParty(string partyName)
{
    // 实现代码...
}
```

**JavaScript调用**:
```javascript
// ✅ 正确：首字母小写
await genshin.switchParty("队伍1");

// ❌ 错误：使用C#的大写形式会报错
await genshin.SwitchParty("队伍1");  // 方法不存在
```

#### 特殊情况

**1. 全大写缩写词保持不变**:
```javascript
// OCR方法保持大写
const result = gameImage.ocr();  // ✅ 正确
```

**2. 属性访问也遵循相同规则**:
```javascript
// C#: public int Width { get; set; }
const width = gameImage.width;  // ✅ 正确（小写w）

// C#: public string Name { get; set; }
const name = task.name;  // ✅ 正确（小写n）
```

**3. 构造函数保持PascalCase**:
```javascript
// 构造函数首字母大写
const task = new SoloTask("AutoFishing");  // ✅ 正确
const hook = new KeyMouseHook();           // ✅ 正确
const timer = new RealtimeTimer();         // ✅ 正确
```

#### 文档中的标注约定

本文档系列中：
- **源码位置标注**: 使用C#原始方法名（PascalCase）
  - 例如：`Genshin.cs:266` - `SwitchParty方法`
- **JavaScript示例**: 使用JavaScript调用方式（camelCase）
  - 例如：`await genshin.switchParty("队伍1")`

#### 常见错误

```javascript
// ❌ 错误：使用C#命名约定
await genshin.Tp(100, 200);              // 应该是 tp
file.ReadTextSync("config.json");        // 应该是 readTextSync
notification.Send("消息");               // 应该是 send

// ✅ 正确：使用JavaScript命名约定
await genshin.tp(100, 200);
file.readTextSync("config.json");
notification.send("消息");
```

#### 调试技巧

如果遇到"方法不存在"的错误，检查方法名首字母是否正确：

```javascript
try {
    // 如果报错"switchParty is not a function"
    await genshin.switchParty("队伍1");
} catch (error) {
    log.error(error.message);
    // 检查是否误用了大写：SwitchParty
}
```

### 模块化最佳实践示例

#### BGI脚本架构标准（基于AutoCommission项目发现）
**完整脚本结构模板**:
```javascript
// 1. 顶层模块加载区域（BGI要求）
eval(file.readTextSync("lib/constants.js"));
eval(file.readTextSync("lib/utils.js"));
eval(file.readTextSync("lib/core.js"));

// 2. 函数定义区域（必须在IIFE之前）
async function executeMainProcess() {
  // 主要业务逻辑
}

async function helperFunction() {
  // 辅助功能函数
}

// 3. BGI标准脚本入口：匿名立即执行异步函数（必须是文件的最后一个表达式）
(async function () {
  try {
    // 所有执行逻辑必须在此
    await executeMainProcess();
    log.info("脚本执行完成");
  } catch (error) {
    log.error("脚本执行出错: " + error.message);
    throw error;
  }
})();
```

#### 关键技术要求
- **模块加载位置**: 必须在文件顶层直接执行eval()
- **变量声明方式**: 模块内必须使用`var`声明，避免`const`/`let`
- **函数定义位置**: 所有函数定义必须在IIFE之前
- **IIFE位置要求**: 匿名立即执行异步函数必须是文件的绝对最后一个表达式
- **返回值要求**: 脚本最后表达式必须返回Promise，不能是VoidResult

#### 技术发现和调试
- **InvalidCastException根因**: 脚本最后表达式返回VoidResult而非Promise
- **作用域限制**: eval导入的变量只能在调用作用域内访问
- **IIFE结构要求**: 必须使用匿名函数`(async function () { ... })()`
