# JavaScript脚本开发 - 像素访问和颜色检测功能

## 概述

BGI（BetterGenshinImpact）的JavaScript环境中，图像数据主要通过`ImageRegion`对象进行处理。BGI支持通过Mat对象的`Get`方法直接获取像素点的RGB值，也提供了多种替代方案实现颜色检测和像素级判断。

## 像素访问方法

### ✅ 支持的功能 - Mat.Get方法

BGI已将OpenCV的`Mat`类型暴露给JavaScript环境，可以直接使用`Get`方法获取像素值：

```javascript
// ✅ 正确：使用Mat的Get方法获取像素RGB值
const gameImage = captureGameRegion();
const mat = gameImage.SrcMat;  // 获取Mat对象

// 获取指定位置的像素值 (注意：参数顺序是 y, x)
const pixelBGR = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, y, x);  // 返回Vec3b对象，包含BGR值

// Vec3b对象包含三个分量 (B, G, R)
const blue = pixelBGR.Item0;   // B分量 (0-255)
const green = pixelBGR.Item1;  // G分量 (0-255) 
const red = pixelBGR.Item2;    // R分量 (0-255)

log.info(`位置(${x}, ${y})的颜色: R=${red}, G=${green}, B=${blue}`);
```

**⚠️ 重要注意事项**：
- 必须使用 `mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, y, x)` 语法，不能使用 `mat.At(y, x)`
- Mat的Get方法参数顺序是`(类型, y, x)`，坐标顺序是先y后x
- 类型参数必须是 `OpenCvSharp.OpenCvSharp.Vec3b`，不能简化
- 返回的是BGR格式，不是RGB格式
- Vec3b对象通过`Item0`、`Item1`、`Item2`访问B、G、R分量

### ❌ 不支持的方法

ImageRegion对象本身不提供像素级访问方法：

```javascript
// ❌ 错误：ImageRegion对象中不存在这些方法
const gameImage = captureGameRegion();
const rgb = gameImage.getPixel(x, y);        // 不存在此方法
const color = gameImage.getRGB(x, y);        // 不存在此方法
const pixel = gameImage.at(x, y);            // 不存在此方法
const pixelColor = gameImage.getPixelColor(x, y); // 不存在此方法
```

### 设计原理

BGI将`ImageRegion`设计为高级图像处理对象，专注于：
- 图像识别（模板匹配）
- 文字识别（OCR）
- 区域裁剪和派生

而不是低级像素操作，这样的设计有以下优势：
1. **性能优化**：避免频繁的像素级操作
2. **简化API**：提供更高层次的图像处理接口
3. **稳定性**：减少因像素级操作导致的错误

## 实际使用示例

### 1. 基础像素获取

```javascript
function getPixelColor(x, y) {
    const gameImage = captureGameRegion();
    const mat = gameImage.SrcMat;
    
    // 注意：Mat的Get方法参数是(类型, y, x)
    const pixelBGR = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, y, x);
    
    return {
        red: pixelBGR.Item2,    // R分量
        green: pixelBGR.Item1,  // G分量  
        blue: pixelBGR.Item0,   // B分量
        bgr: pixelBGR          // 原始BGR对象
    };
}

// 使用示例
const color = getPixelColor(100, 200);
log.info(`像素颜色: R=${color.red}, G=${color.green}, B=${color.blue}`);
```

### 2. 颜色判断函数

```javascript
// 判断是否为白色（容忍度范围内）
function isWhiteColor(pixelBGR, tolerance = 10) {
    const r = pixelBGR.Item2;
    const g = pixelBGR.Item1; 
    const b = pixelBGR.Item0;
    
    return Math.abs(r - 255) <= tolerance && 
           Math.abs(g - 255) <= tolerance && 
           Math.abs(b - 255) <= tolerance;
}

// 判断是否为特定颜色
function isColorMatch(pixelBGR, targetR, targetG, targetB, tolerance = 15) {
    const r = pixelBGR.Item2;
    const g = pixelBGR.Item1;
    const b = pixelBGR.Item0;
    
    return Math.abs(r - targetR) <= tolerance &&
           Math.abs(g - targetG) <= tolerance &&
           Math.abs(b - targetB) <= tolerance;
}

// 使用示例
const gameImage = captureGameRegion();
const mat = gameImage.SrcMat;
const pixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, 100, 200);  // 获取(200, 100)位置的像素

if (isWhiteColor(pixel)) {
    log.info("检测到白色");
} else if (isColorMatch(pixel, 255, 0, 0)) {  // 检测红色
    log.info("检测到红色");
}
```

// 基于BGI源码的实际应用示例
function checkHealthStatus() {
    const gameImage = captureGameRegion();
    const mat = gameImage.SrcMat;
    
    // 检测进度条颜色 (参考BGI源码的实际坐标)
    const progressBarPixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, 790, 50);  // 注意参数顺序是(y, x)
    const whiteTilePixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, 768, 50);
    
    // 判断是否为白色瓷砖
    function isWhite(r, g, b) {
        return r > 240 && g > 240 && b > 240;
    }
    
    // 判断是否为黄色进度条
    function isYellow(r, g, b) {
        return r > 200 && g > 200 && b < 100;
    }
    
    const whiteCheck = isWhite(whiteTilePixel.Item2, whiteTilePixel.Item1, whiteTilePixel.Item0);
    const yellowCheck = isYellow(progressBarPixel.Item2, progressBarPixel.Item1, progressBarPixel.Item0);
    
    return {
        hasWhiteTile: whiteCheck,
        hasYellowProgressBar: yellowCheck,
        isHealthy: whiteCheck && yellowCheck
    };
}

### 4. 多点颜色检测

```javascript
// 检测多个关键位置的颜色
function checkMultiplePixelColors(positions) {
    const gameImage = captureGameRegion();
    const mat = gameImage.SrcMat;
    const results = [];
    
    for (const pos of positions) {
        try {
            const pixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, pos.y, pos.x);  // 注意参数顺序
            results.push({
                position: pos,
                color: {
                    red: pixel.Item2,
                    green: pixel.Item1,
                    blue: pixel.Item0
                },
                isTarget: isColorMatch(pixel, pos.targetR, pos.targetG, pos.targetB)
            });
        } catch (error) {
            log.error(`获取位置(${pos.x}, ${pos.y})像素失败: ${error.message}`);
            results.push({
                position: pos,
                error: error.message
            });
        }
    }
    
    return results;
}

// 使用示例
const checkPoints = [
    {x: 100, y: 200, targetR: 255, targetG: 0, targetB: 0},    // 检测红色
    {x: 150, y: 250, targetR: 0, targetG: 255, targetB: 0},    // 检测绿色
    {x: 200, y: 300, targetR: 0, targetG: 0, targetB: 255}     // 检测蓝色
];

const colorResults = checkMultiplePixelColors(checkPoints);
colorResults.forEach(result => {
    if (result.error) {
        log.error(`位置(${result.position.x}, ${result.position.y})检测失败`);
    } else {
        log.info(`位置(${result.position.x}, ${result.position.y}): ${result.isTarget ? '匹配' : '不匹配'}目标颜色`);
    }
});
```

### 5. 区域颜色统计

```javascript
// 统计指定区域内的颜色分布
function analyzeRegionColors(x, y, width, height) {
    const gameImage = captureGameRegion();
    const mat = gameImage.SrcMat;
    
    const colorCount = {
        red: 0,
        green: 0, 
        blue: 0,
        white: 0,
        black: 0,
        total: 0
    };
    
    // 遍历指定区域的像素
    for (let py = y; py < y + height && py < mat.Height; py++) {
        for (let px = x; px < x + width && px < mat.Width; px++) {
            try {
                const pixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, py, px);  // 注意参数顺序
                const r = pixel.Item2;
                const g = pixel.Item1;
                const b = pixel.Item0;
                
                colorCount.total++;
                
                // 简单颜色分类
                if (r > 200 && g < 100 && b < 100) colorCount.red++;
                else if (r < 100 && g > 200 && b < 100) colorCount.green++;
                else if (r < 100 && g < 100 && b > 200) colorCount.blue++;
                else if (r > 200 && g > 200 && b > 200) colorCount.white++;
                else if (r < 50 && g < 50 && b < 50) colorCount.black++;
                
            } catch (error) {
                // 忽略越界错误，继续处理
            }
        }
    }
    
    // 计算比例
    const ratios = {};
    Object.keys(colorCount).forEach(color => {
        if (color !== 'total') {
            ratios[color] = colorCount.total > 0 ? (colorCount[color] / colorCount.total * 100).toFixed(2) + '%' : '0%';
        }
    });
    
    return {
        counts: colorCount,
        ratios: ratios
    };
}

// 使用示例
const regionAnalysis = analyzeRegionColors(100, 100, 200, 150);
log.info('区域颜色分析:', regionAnalysis.ratios);
```

function checkPixelColor(x, y, templatePath) {
  const gameImage = captureGameRegion();
  
  // 裁剪目标像素周围的小区域（如5x5像素）
  const pixelRegion = gameImage.DeriveCrop(x-2, y-2, 5, 5);

    file.readImageMatSync(templatePath),
    0, 0, 5, 5
  );
  
  const result = pixelRegion.Find(colorTemplate);
  return !result.isEmpty();

### 5. 区域颜色统计

通过OCR配合正则表达式，实现区域级别的颜色判断：

```javascript
// 通过区域特征判断颜色状态
function analyzeRegionColor(x, y, width, height) {
  const gameImage = captureGameRegion();
  const targetRegion = gameImage.DeriveCrop(x, y, width, height);
  
  // 可以通过OCR识别区域内的文字，间接判断颜色状态
  const ocrResult = targetRegion.ocr();
  
  // 或者使用模板匹配检测区域特征
  const features = [
    "assets/bright_region.png",
    "assets/dark_region.png", 
    "assets/colored_region.png"
  ];
  
  for (const feature of features) {
    const template = RecognitionObject.TemplateMatch(
      file.readImageMatSync(feature),
      0, 0, width, height
    );
    
    const result = targetRegion.Find(template);
    if (!result.isEmpty()) {
      return feature.split('/').pop().split('.')[0]; // 返回特征名称
    }
  }
  
  return "unknown";
}
```

## 最佳实践

### 1. 模板缓存

```javascript
// 缓存模板避免重复加载
const templateCache = {};

function getTemplate(templatePath) {
  if (!templateCache[templatePath]) {
    templateCache[templatePath] = file.readImageMatSync(templatePath);
  }
  return templateCache[templatePath];
}
```

### 2. 容错处理

```javascript
// 带容错的颜色检测
function robustColorCheck(x, y, templatePath, retries = 3) {
  for (let i = 0; i < retries; i++) {
    try {
      const result = checkPixelColor(x, y, templatePath);
      return result;
    } catch (error) {
      log.warn(`颜色检测失败，重试 ${i + 1}/${retries}: ${error.message}`);
      sleep(100); // 等待100ms后重试
    }
  }
  return false;
}
```

### 3. 区域优化

```javascript
// 限制检测区域以提高性能
function optimizedColorCheck(targetX, targetY, searchRadius = 50) {
  const gameImage = captureGameRegion();
  
  // 只在目标位置周围搜索，而不是全屏
  const searchRegion = gameImage.DeriveCrop(
    Math.max(0, targetX - searchRadius),
    Math.max(0, targetY - searchRadius),
    Math.min(gameImage.Width, searchRadius * 2),
    Math.min(gameImage.Height, searchRadius * 2)
  );
  
  // 在限定区域内进行检测
  const template = RecognitionObject.TemplateMatch(
    getTemplate("assets/target_color.png"),
    0, 0, searchRadius * 2, searchRadius * 2
  );
  
  return !searchRegion.Find(template).isEmpty();
}
```

## 总结

BGI JavaScript环境完全支持直接的像素访问，提供了两种主要方案：

### 方案1：直接像素访问（推荐）
通过 `mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, y, x)` 方法：

1. **精确像素检测**：直接获取任意位置的BGR值
2. **高性能访问**：直接内存访问，速度最快
3. **完整颜色信息**：获取完整的BGR分量数据
4. **灵活的区域分析**：可以实现任意复杂的颜色分析算法

### 方案2：模板匹配（辅助）
通过预制模板进行颜色和图像识别：

1. **稳定的UI检测**：不依赖精确像素位置
2. **复杂图案识别**：识别按钮、图标等UI元素
3. **颜色范围识别**：检测特定颜色范围的区域
4. **状态判断**：通过UI变化判断游戏状态

### 推荐使用策略
- **精确颜色检测**：优先使用直接像素访问
- **UI元素识别**：使用模板匹配
- **复合检测**：结合两种方法提高准确性
- **内存优化**：限制像素访问的坐标范围

直接像素访问方法简单直观且性能优秀，是BGI JavaScript环境中颜色检测的首选方案。
