# JavaScript脚本开发 - 绘图和可视化功能

## 概述

BGI（BetterGenshinImpact）为JavaScript脚本开发提供了**有限的**绘图和可视化功能。基于实际测试，BGI支持基础的矩形和线条绘制，但不支持高级功能如自定义颜色、清除操作等。

**重要说明**: 本文档基于实际测试结果编写，与BGI源码中的完整VisionContext实现不同。JavaScript环境中只暴露了部分基础功能。

**主要实现位置**:
- Region绘制方法: `BetterGenshinImpact\GameTask\Model\Area\Region.cs:207-281`

---

## 实际可用的绘图功能

### 基础矩形绘制

```javascript
// 获取游戏区域
const region = captureGameRegion();

// 绘制基础矩形（使用默认红色画笔，线宽2）
region.DrawRect(100, 50, 200, 150, "myRect");

// 绘制多个矩形
region.DrawRect(100, 250, 150, 100, "rect1");
region.DrawRect(300, 250, 150, 100, "rect2");
region.DrawRect(500, 250, 150, 100, "rect3");
```

**参数说明**:
- `x, y` (number): 矩形左上角坐标
- `w, h` (number): 矩形宽度和高度
- `name` (string): 绘制对象的唯一标识名称

**测试结果**: ✅ 功能正常，使用默认红色画笔

### 基础线条绘制

```javascript
// 绘制基础线条（使用默认红色画笔，线宽2）
region.DrawLine(100, 100, 300, 200, "myLine");

// 绘制多条线条
region.DrawLine(150, 400, 250, 500, "line1");
region.DrawLine(300, 400, 400, 500, "line2");
region.DrawLine(450, 400, 550, 500, "line3");
```

**参数说明**:
- `x1, y1` (number): 线条起点坐标
- `x2, y2` (number): 线条终点坐标
- `name` (string): 绘制对象的唯一标识名称

**测试结果**: ✅ 功能正常，使用默认红色画笔

### 区域边框绘制

```javascript
// 绘制整个游戏区域的边框
const region = captureGameRegion();
region.DrawSelf("regionBorder");
```

**测试结果**: ✅ 功能正常，绘制游戏窗口边框

## 变通解决方案

### 🔧 "清除"功能的变通实现

虽然无法直接访问VisionContext的清除方法，但发现了一个**变通的清除方案**：

#### 零大小图形覆盖法
```javascript
// ✅ 变通方案：通过绘制零大小的图形来"清除"现有图形
// 使用相同的name来覆盖现有图形

// 清除矩形的变通方法
region.DrawRect(0, 0, 0, 0, "要清除的矩形name");

// 清除线条的变通方法  
region.DrawLine(0, 0, 0, 0, "要清除的线条name");

// 实际应用示例
region.DrawRect(100, 100, 200, 150, "testRect");  // 绘制矩形
await sleep(2000);
region.DrawRect(0, 0, 0, 0, "testRect");          // "清除"矩形
```

**工作原理**：
- 使用相同的name绘制零大小的图形
- BGI会用新的零大小图形替换原有图形
- 由于零大小图形不可见，达到"清除"效果

**使用场景**：
- 需要动态显示/隐藏特定图形
- 临时标记后需要清除
- 条件性显示调试信息

**限制**：
- 这是一个"无奈的方案"，不是真正的清除
- 需要记住每个图形的name才能清除
- 无法一次性清除所有图形
- 图形对象仍然存在，只是不可见

### 示例4: 动态绘图管理（使用变通清除方案）

```javascript
// 动态显示/隐藏图形的完整示例
const region = captureGameRegion();

// 绘图管理器
const DrawingManager = {
    // 显示状态追踪
    visible: {},
    
    // 绘制矩形
    showRect: function(name, x, y, w, h) {
        region.DrawRect(x, y, w, h, name);
        this.visible[name] = true;
        log.info("显示矩形: {}", name);
    },
    
    // 绘制线条
    showLine: function(name, x1, y1, x2, y2) {
        region.DrawLine(x1, y1, x2, y2, name);
        this.visible[name] = true;
        log.info("显示线条: {}", name);
    },
    
    // "清除"矩形（变通方案）
    hideRect: function(name) {
        region.DrawRect(0, 0, 0, 0, name);
        this.visible[name] = false;
        log.info("隐藏矩形: {}", name);
    },
    
    // "清除"线条（变通方案）
    hideLine: function(name) {
        region.DrawLine(0, 0, 0, 0, name);
        this.visible[name] = false;
        log.info("隐藏线条: {}", name);
    },
    
    // 切换显示状态
    toggle: function(name, type, ...params) {
        if (this.visible[name]) {
            if (type === 'rect') {
                this.hideRect(name);
            } else if (type === 'line') {
                this.hideLine(name);
            }
        } else {
            if (type === 'rect') {
                this.showRect(name, ...params);
            } else if (type === 'line') {
                this.showLine(name, ...params);
            }
        }
    }
};

// 使用示例
DrawingManager.showRect("healthBar", 100, 100, 200, 20);
await sleep(2000);

DrawingManager.showLine("crosshair", 200, 50, 200, 150);
await sleep(2000);

// 隐藏图形
DrawingManager.hideRect("healthBar");
await sleep(2000);

// 重新显示
DrawingManager.showRect("healthBar", 100, 100, 200, 20);
await sleep(2000);

// 切换显示
DrawingManager.toggle("crosshair", "line", 200, 50, 200, 150);
```

## 功能限制

### ❌ 确认不支持的功能

**通过实际测试确认**，以下功能在BGI JavaScript环境中**不可用**：

#### 1. 自定义画笔和颜色
```javascript
// ❌ 以下代码会报错：System is not defined
const redPen = new System.Drawing.Pen(System.Drawing.Color.Red, 3);
region.DrawRect(100, 100, 200, 150, "rect", redPen);
```
**测试结果**: System.Drawing命名空间未暴露给JavaScript环境

#### 2. VisionContext和清除功能
```javascript
// ❌ 以下代码会报错：VisionContext is not defined
const visionContext = VisionContext.Instance();
const drawContent = visionContext.DrawContent;
drawContent.RemoveRect("myRect");
drawContent.RemoveLine("myLine");
drawContent.ClearAll();
```
**测试结果**: VisionContext类未暴露给JavaScript环境

#### 3. 数学函数（反射限制）
```javascript
// ❌ 以下代码会报错：Use of reflection is prohibited
const x = Math.cos(angle) * radius;
const y = Math.sin(angle) * radius;
```

#### 4. 复杂图形绘制
由于Math函数不可用，无法通过计算绘制圆形、弧形等复杂图形。

## 使用注意事项

### 1. 默认样式
- 所有绘制都使用默认的红色画笔
- 默认线宽为2像素
- 无法自定义颜色或线宽

### 2. 无清除功能
- 绘制的图形会一直保留
- 无法单独清除指定图形
- 无法一次性清除所有图形
- 重启BGI或重新运行脚本可能清除图形

### 3. 坐标系统
- 坐标基于游戏窗口的捕获区域
- 左上角为(0,0)，向右向下为正方向
- 需要考虑DPI缩放的影响

### 4. 性能考虑
- 避免绘制过多图形
- 复杂图形可能影响游戏性能
- 使用有意义的名称便于调试

## 与文档的差异说明

**重要**: BGI源码中包含完整的VisionContext绘图系统，支持：
- 自定义画笔颜色（System.Drawing.Pen）
- 清除功能（RemoveRect/RemoveLine/ClearAll）
- 复杂图形绘制
- 文本绘制

但是，**在JavaScript环境中这些功能不可用**，可能的原因：
1. BGI的JavaScript引擎没有暴露VisionContext类
2. System命名空间没有注入到JavaScript环境
3. 反射功能被禁用，限制了Math函数的使用
4. 出于安全考虑限制了高级绘图功能

## 总结

BGI JavaScript环境的绘图功能经过完整测试验证，分为两个层次：

### ✅ 确认可用的功能
- ✅ `region.DrawRect(x, y, w, h, name)` - 矩形绘制
- ✅ `region.DrawLine(x1, y1, x2, y2, name)` - 线条绘制  
- ✅ `region.DrawSelf(name)` - 边框绘制
- 使用默认红色画笔，线宽2像素

### 🔧 变通可用的功能
- 🔧 **"清除"矩形**：`region.DrawRect(0, 0, 0, 0, name)` 
- 🔧 **"清除"线条**：`region.DrawLine(0, 0, 0, 0, name)`
- 通过零大小图形覆盖实现"清除"效果（无奈方案）

### ❌ 确认不可用的功能
- ❌ 自定义颜色和线宽（System.Drawing.Pen不可访问）
- ❌ 清除功能（VisionContext.Instance().DrawContent不可访问）
- ❌ Math.cos/sin等数学函数（反射限制）
- ❌ 复杂图形绘制（受Math函数限制）

**实际应用场景**：
- 简单的区域标注和调试辅助
- 基础的UI元素位置标记
- 坐标参考线绘制
- **动态显示/隐藏图形**（使用零大小覆盖法）
- 临时标记和条件性显示

**重要发现**：
- ✅ 发现了变通的"清除"方案（零大小图形覆盖）
- 可以实现图形的动态显示/隐藏效果
- 需要记住图形名称才能进行"清除"操作
