```javascript
for (var i = 0; i < artifact.MinorAffixes.length; i++) {

    totalScore += affix.Value;      // 暴击伤害权重1
```

### 键盘事件监听

```javascript
hook.OnKeyDown(callback, [useCodeOnly=true]) // 参数: (keyCode) => void

```

### 鼠标事件监听
```javascript
// 监听鼠标按下事件（坐标已自动转换为游戏窗口局部坐标）
hook.OnMouseDown(callback) // 参数: (button, localX, localY) => void

// 监听鼠标释放事件（坐标已自动转换为游戏窗口局部坐标）
hook.OnMouseUp(callback) // 参数: (button, localX, localY) => void

// 监听鼠标移动事件（可设置间隔避免过度触发）
hook.OnMouseMove(callback, [interval=200]) // 参数: (localX, localY) => void

// 监听鼠标滚轮事件
hook.OnMouseWheel(callback) // 参数: (delta, localX, localY) => void
```

### 资源管理
```javascript
hook.RemoveAllListeners() // 移除所有监听器（不释放钩子资源）
hook.Dispose() // 释放钩子资源（必须在脚本结束前调用）
```

### ⚠️ 重要提示
- **必须释放资源**: 脚本结束前必须调用 `hook.Dispose()` 释放全局钩子资源
- **坐标自动转换**: 鼠标事件的坐标已自动转换为游戏窗口局部坐标
- **性能优化**: 鼠标移动事件建议设置合理的间隔时间（默认200ms）

### 快速示例
```javascript
const hook = new KeyMouseHook();

// 监听F1键启动/暂停脚本
let isRunning = false;
hook.OnKeyDown((keyCode) => {
    if (keyCode === 'F1') {
        isRunning = !isRunning;
        log.info(isRunning ? '脚本启动' : '脚本暂停');
    }
});

// 监听鼠标点击记录坐标
hook.OnMouseDown((button, x, y) => {
    if (button === 'Left') {
        log.info(`记录坐标: (${x}, ${y})`);
    }
});

// 脚本结束前释放资源
hook.Dispose();
```

## 注意事项

### ❌ 不可使用的功能
- 网络API：fetch、XMLHttpRequest、WebSocket
- 浏览器API：DOM操作、BOM对象
- Node.js模块：require不稳定
- 定时器：setTimeout、setInterval等
- 现代JS特性：Promise构造函数等

### ⚠️ 重要注意事项
- Mat.Get()参数顺序是(类型, y, x)，类型必须是OpenCvSharp.OpenCvSharp.Vec3b
- 像素格式是BGR，不是RGB
- ImageRegion对象需要手动调用Dispose()释放资源
- OCR区域对象必须包含X、Y、WIDTH、HEIGHT四个属性
- const声明在eval中无法跨作用域，必须使用var
- 脚本必须以异步IIFE结尾：`(async function(){ ... })()`
