# 第一部分：OpenCV和图像处理类型

## Mat - 图像矩阵对象

### 基础概念

`Mat`是OpenCV的核心图像对象，代表一个多维数组,通常用于存储图像数据。

```javascript
// Mat对象通常通过其他方法获得，很少直接创建
const gameImage = captureGameRegion();
const mat = gameImage.SrcMat;  // 获取Mat对象

// Mat对象的基本属性
log.info(`图像尺寸: ${mat.Width} x ${mat.Height}`);
log.info(`图像通道数: ${mat.Channels()}`);
log.info(`图像类型: ${mat.Type()}`);
```

### 像素访问

```javascript
// 获取指定位置的像素值 (注意：参数顺序是 y, x)
const gameImage = captureGameRegion();
const mat = gameImage.SrcMat;

// 获取像素BGR值
const pixelBGR = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, 100, 200);  // y=100, x=200
const blue = pixelBGR.Item0;        // B分量 (0-255)
const green = pixelBGR.Item1;       // G分量 (0-255)
const red = pixelBGR.Item2;         // R分量 (0-255)

log.info(`位置(200,100)的颜色: R=${red}, G=${green}, B=${blue}`);
```

### 实用像素操作示例

```javascript
// 颜色检测函数
function detectColor(mat, x, y, targetR, targetG, targetB, tolerance = 10) {
    try {
        const pixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, y, x);  // 注意y,x顺序
        const r = pixel.Item2;
        const g = pixel.Item1;
        const b = pixel.Item0;
        
        return Math.abs(r - targetR) <= tolerance && 
               Math.abs(g - targetG) <= tolerance && 
               Math.abs(b - targetB) <= tolerance;
    } catch (error) {
        log.error(`像素访问失败: ${error.message}`);
        return false;
    }
}

// 区域颜色分析
function analyzeRegionColor(mat, x, y, width, height) {
    let totalR = 0, totalG = 0, totalB = 0;
    let pixelCount = 0;
    
    for (let py = y; py < y + height; py += 5) {  // 采样间隔
        for (let px = x; px < x + width; px += 5) {
            try {
                const pixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, py, px);
                totalR += pixel.Item2;
                totalG += pixel.Item1;
                totalB += pixel.Item0;
                pixelCount++;
            } catch (error) {
                // 忽略边界外的像素
            }
        }
    }
    
    if (pixelCount > 0) {
        return {
            avgR: Math.round(totalR / pixelCount),
            avgG: Math.round(totalG / pixelCount),
            avgB: Math.round(totalB / pixelCount),
            pixelCount: pixelCount
        };
    }
    
    return null;
}
```

### Point2f计算操作

```javascript
// 距离计算
function calculateDistance(point1, point2) {
    const dx = point2.X - point1.X;
    const dy = point2.Y - point1.Y;
    return Math.sqrt(dx * dx + dy * dy);
}

// 中点计算
function getMidpoint(point1, point2) {
    return new Point2f(
        (point1.X + point2.X) / 2,
        (point1.Y + point2.Y) / 2
    );
}

// 使用示例
const pos1 = genshin.getPositionFromMap();
const targetPos = new Point2f(1000, 2000);
const distance = calculateDistance(pos1, targetPos);

if (distance > 100) {
    log.info(`距离目标${distance.toFixed(2)}，需要移动`);
    await genshin.tp(targetPos.X, targetPos.Y);
}
```

## CombatScenes - 战斗场景管理

### 基础概念

`CombatScenes`类用于管理战斗场景中的所有信息，包括队伍角色、敌人检测、战斗状态分析等。它是BGI自动战斗系统的核心组件。

```javascript
// 创建战斗场景对象
const combatScene = new CombatScenes();

// CombatScenes主要用于战斗相关的场景分析
// 通常配合自动战斗功能使用
```

### 主要功能特性

基于源码分析，CombatScenes提供以下核心功能：

1. **队伍管理**: 管理当前队伍中的角色信息
2. **敌人检测**: 使用YOLO模型检测敌人位置
3. **UI适配**: 支持不同版本的UI布局
4. **战斗状态**: 监控当前战斗状态

```javascript
// 战斗场景使用示例

        log.error(`战斗场景初始化失败: ${error.message}`);

// 角色信息管理类
class PartyManager {
    constructor() {
        this.avatars = [];
        this.currentAvatarIndex = 0;
    }
    
    // 初始化队伍
    initializeParty() {
        try {
            // 获取当前队伍角色
            const avatarNames = getAvatars();  // 全局方法
            
            this.avatars = [];
            for (let i = 0; i < avatarNames.length; i++) {
                const avatar = new Avatar();
                avatar.Name = avatarNames[i];
                avatar.Index = i + 1;
                avatar.ManualSkillCd = -1;  // 使用自动CD检测
                
                this.avatars.push(avatar);
            }
            
            log.info(`队伍初始化完成: ${avatarNames.join(', ')}`);
            return true;
            
        } catch (error) {
            log.error(`队伍初始化失败: ${error.message}`);
            return false;
        }
    }
    
    // 获取指定角色
    getAvatar(index) {
        if (index >= 0 && index < this.avatars.length) {
            return this.avatars[index];
        }
        return null;
    }
    
    // 切换角色
    switchToAvatar(index) {
        if (index >= 0 && index < this.avatars.length) {
            this.currentAvatarIndex = index;
            
            // 执行角色切换操作
            const keyMap = ['VK_1', 'VK_2', 'VK_3', 'VK_4'];
            if (keyMap[index]) {
                keyPress(keyMap[index]);
                log.info(`切换到角色 ${index + 1}: ${this.avatars[index].Name}`);
            }
        }
    }
}
```

## 注意事项

### ⚠️ 重要提醒

#### 图像处理类型
1. **坐标顺序**: Mat.Get()方法的参数顺序是(Vec3b类型, y, x)，需要指定类型参数
2. **颜色格式**: 像素返回BGR格式，不是RGB格式
3. **资源管理**: ImageRegion对象需要手动调用Dispose()释放资源
4. **类型创建**: 大部分类型需要通过new关键字创建实例

#### 战斗系统类型
1. **资源管理**: CombatScenes可能需要手动释放资源，注意调用Dispose()
2. **角色同步**: Avatar信息需要与游戏内实际状态保持同步
3. **性能考虑**: 战斗检测应设置合理的检测间隔，避免过度消耗CPU
4. **错误处理**: 战斗相关操作可能失败，需要完善的错误处理机制

### ❌ 常见错误

```javascript
// ❌ 错误：Mat.Get()参数顺序或类型错误
const pixel = mat.Get(OpenCvSharp.OpenCvSharp.Vec3b, x, y);  // 应该是(类型, y, x)

// ❌ 错误：未释放ImageRegion资源
const gameImage = captureGameRegion();
// 忘记调用gameImage.Dispose()

// ❌ 错误：颜色格式混淆
const red = pixel.Item0;     // Item0是B分量，不是R分量

// ❌ 错误：未释放CombatScenes资源
const combatScene = new CombatScenes();
// 忘记调用combatScene.Dispose()

// ❌ 错误：Avatar信息未更新
const avatar = new Avatar();
avatar.Name = "旧角色名";  // 未与游戏实际状态同步

// ❌ 错误：过度频繁的战斗检测
while (true) {
    detectCombatState();  // 无间隔检测，消耗过多资源
}
```
